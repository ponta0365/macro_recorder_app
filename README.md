# キーボード・マウス操作記録アプリ

キーボードとマウスの操作を記録し、あとから再生できるシンプルなデスクトップアプリです。

## これは何か

- 操作を時系列で記録する
- 記録した操作を再生する
- 操作一覧を編集する
- 複数プロジェクトを連結して実行する
- クリップボード、文字列、ファイル内容を使った条件分岐を入れる
- ループを含む実行フローを組む
- フロー画面では `Then / Elif / Else / Body` の枝を持つツリーとして編集する
- `while` 風ループにも切り替えられる
- テンプレートからフローのひな形を作れる
- フロー内の各ノードは有効 / 無効を切り替えられる
- フロー内のノードはドラッグして並べ替えられる
- 条件分岐は `contains` / `not_contains` / `equals` / `not_equals` / `startswith` / `endswith` / `regex` / `is_empty` / `not_empty` に対応する
- ファイル内容を条件に使うときは文字コードも指定できる
- JSON で保存・読み込みする
- URL / EXE / BAT / CMD / PowerShell / フォルダ起動に対応する
- `Esc` で記録停止・再生停止できる
- 再生開始前確認をオン / オフで切り替えられる
- ステップごとの個別確認も設定できる
- 起動中に `Ctrl + Alt + 1` 〜 `Ctrl + Alt + 9` で割り当て済みプロジェクトを再生できる
- 一覧画面にプロジェクトショートカット一覧をまとめて表示する
- プロジェクト一覧は「ショートカット順」と「最近使った順」を切り替えられる
- プロジェクト一覧画面にはショートカット一覧もまとめて表示する
- ショートカット一覧では、行をドラッグして `Ctrl + Alt + 1..9` の割り当てを変更できる
- 9個を超えたプロジェクトは未割当として表示する

## AI による作成について

このプログラムは AI 支援で作成されています。
設計、実装、説明書の整備には AI コーディング支援を使用しています。

## 起動方法

### 1. 依存関係を入れる

`setup.bat` を実行します。

### 2. アプリを起動する

`start_macro_recorder.bat` を実行します。

## 使い方

1. `記録開始` を押す
2. 普段どおりに操作する
3. `Esc` で記録を終了する
4. 一覧から行をクリックして編集する
5. `保存` で JSON として保存する
6. `再生` で記録を実行する

## 編集できる項目

- 表示名
- 内容
- 待機時間
- 有効 / 無効
- 座標
- プロジェクトショートカット
- 実行フロー

## マウス移動について

- `マウス移動を記録` をオンにすると移動も記録する
- オフのときは移動を保存せず、待機時間として扱う

## 日本語入力について

- 半角 / 全角 / 日本語入力を区別して記録する
- 日本語や全角文字は clipboard 経由で再生する

## 安全機能

- `Esc` で即停止
- `pyautogui` の fail-safe を有効化
- 左上移動で停止

## 保存形式

JSON プロジェクトとして保存します。
