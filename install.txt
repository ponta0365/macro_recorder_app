キーボード・マウス操作記録アプリ 配布版

1. `setup.bat` を実行して依存関係をインストールしてください。
2. `start_macro_recorder.bat` を実行してアプリを起動してください。
3. 画面の `Esc` で記録停止 / 再生停止できます。
4. プロジェクトの再生は `Ctrl + Alt + 1` 〜 `Ctrl + Alt + 9` で実行できます。
5. ショートカット一覧の行をドラッグすると割り当てを変更できます。
6. `フロー` 画面で複数プロジェクトの連結、条件分岐、ループを編集できます。
7. `フロー` は `Then / Elif / Else / Body` のツリー構造で、テンプレートからひな形を作れます。
8. 条件分岐はクリップボード、文字列、ファイル内容を対象にできます。
9. ファイル内容の条件判定では文字コードも指定できます。
10. フロー内のノードは有効 / 無効を切り替えたり、ドラッグで並べ替えたりできます。
11. 再生開始前確認はオン / オフを切り替えられます。
12. ステップごとの個別確認も使えます。

必要ファイル:
- `macro_recorder_app.py`
- `requirements.txt`
- `setup.bat`
- `start_macro_recorder.bat`
- `README.md`
- `ACKNOWLEDGEMENTS.md`
- `LICENSE`

注意:
- Python がインストールされている必要があります。
- 日本語入力の再生には `pyperclip` を使用します。
- 本ソフトウェアは GPLv3 です。
